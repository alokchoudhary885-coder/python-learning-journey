# Chapter 3 - Control Flow in Python

This chapter covers how Python controls the order and execution path of statements using conditional decisions and iterative loops.

## Topics Covered
- Decision Making: `if`, `elif`, `else` statements
- Logical Operators (`and`, `or`, `not`) and Short-Circuit Evaluation
- Structural Pattern Matching (`match-case`)
- Iterative Loops: `for` loops, `while` loops, and sequence traversal
- Loop Control Keywords: `break`, `continue`, `pass`
- Python's unique `for...else` and `while...else` constructs

## Files in this Chapter
- `conditional_statements.py`: Demonstration of if-elif-else, nested conditionals, logical operators, and match-case.
- `conditional_statements.md`: 10-section study notes on decision making with syntax, rules, and practice questions.
- `iterative_statements.py`: For and while loops, range generation, loop control, and for-else patterns.
- `loops_and_iteration.md`: 10-section study notes on loops, sequence iteration, break/continue, and questions.

## How to Run
```bash
python conditional_statements.py
```
