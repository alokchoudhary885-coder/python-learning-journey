# Chapter 1 - Python Fundamentals

This chapter covers foundational concepts of Python programming: variables, comments, indentation, expressions, and statements.

## Topics Covered
- Python Variables and dynamic typing
- Comments (single-line, multi-line, docstrings)
- Expressions vs Statements
- Indentation rules in Python
- Control flow statement basics (`if`, `for`, `while`)

## Files in this Chapter
- `01_variables.py`: Variable declaration and usage.
- `comment.py`: Different types of comments and docstrings.
- `expressions_and_statements.py`: Difference between expressions and statements.
- `indentation.py`: Code blocks and indentation examples.
- `python-statements.py`: Survey of Python statement types.
- `practice.py`: Practical exercises combining fundamentals.
- `assignment.py`: Chapter assignment with solved tasks.
- `notes.md`: Quick revision notes, syntax, common pitfalls, and questions.

## How to Run
```bash
python 01_variables.py
python practice.py
python assignment.py
```
