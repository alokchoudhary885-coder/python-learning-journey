# Chapter 7 - File Handling & Exception Handling in Python

This chapter covers robust error handling with exceptions and managing persistent file storage (reading, writing, and context managers).

## Topics Covered
- Exceptions vs Syntax Errors
- The `try`, `except`, `else`, and `finally` execution lifecycle
- Handling multiple specific exception types
- The `raise` keyword and custom user-defined exceptions
- File Handling: `open()`, reading, writing, appending, and `with` context managers (Up Next)
- JSON and CSV processing (Up Next)

## Files in this Chapter
- `exception_handling.py`: Demonstrates division error handling, multiple exception catching, full try-else-finally flow, raising errors, and custom exceptions.
- `exception_handling.md`: 10-section study notes on exception hierarchies, cleanup safety, best practices, and practice questions.

## How to Run
```bash
python exception_handling.py
```
