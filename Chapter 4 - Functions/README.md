# Chapter 4 - Functions, Variable Scope & Recursion

This chapter introduces reusable blocks of logic (functions), parameter passing, variable-length arguments (`*args`, `**kwargs`), local and global variable scope, and recursive problem solving.

## Topics Covered
- Function definition (`def`) and return statements
- Positional and keyword arguments
- Default parameters
- Variable-length keyword arguments (`**kwargs`)
- **Variable Scope:** Local variables vs Global variables
- Variable shadowing and the `global` keyword
- The `LEGB` rule (Local, Enclosing, Global, Built-in)
- Recursion: base case, recursive case, and call stack unwinding
- Factorial implementation vs Python's built-in `math.factorial()`

## Files in this Chapter
- `practice.py`: Basic function declarations, arithmetic operations, and keyword argument handling.
- `variable_scope.py`: Detailed demonstration of local variables, global variables, shadowing, and the `global` keyword.
- `recursion.py`: Clean recursive factorial implementation with step-by-step formula tracing.
- `assignment.py`: Practical problem sets including power calculation, recursive sum of digits, and global visitor counter.
- `notes.md`: Detailed revision notes, call stack tracing, scope rules, common mistakes, and practice questions.

## How to Run
```bash
python practice.py
python variable_scope.py
python recursion.py
python assignment.py
```
