# Chapter 0 - Getting Started

## 1. Definition
Python is a popular, high-level, and easy-to-read programming language. Getting started involves running your first program using the `print()` function to display text or numbers on the screen.

## 2. Syntax
```python
print("Your message here")
```

## 3. Example
```python
# First Python program
print("Hello, World!")
print("Welcome to my Python Learning Journey!")
```

## 4. Output
```text
Hello, World!
Welcome to my Python Learning Journey!
```

## 5. Explanation
- `print()` is a built-in function in Python that sends data to standard output (the terminal or console).
- The text inside quotes (`"..."` or `'...'`) is a string literal.
- Python runs code sequentially from top to bottom.

## 6. Important Points
- Python is case-sensitive (`print` is valid, but `Print` will cause an error).
- Strings can be enclosed in single quotes `'...'` or double quotes `"..."`.
- Every call to `print()` ends with a new line by default.

## 7. Common Mistakes
- Writing `Print()` with a capital `P`.
- Forgetting opening or closing quotation marks.
- Forgetting closing parentheses `)`.
