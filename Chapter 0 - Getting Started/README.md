# Chapter 0 - Getting Started

This chapter covers the absolute basics of setting up and running your first Python program.

## Topics Covered
- Introduction to Python
- The `print()` function
- Running Python scripts from the terminal

## Files in this Chapter
- `01_hello_world.py`: The classic beginner's first Python program.
- `practice.py`: Basic printing examples and variations.
- `notes.md`: Quick revision notes, syntax, common mistakes, and practice questions.

## How to Run
Run any script using the Python command:
```bash
python 01_hello_world.py
python practice.py
```
