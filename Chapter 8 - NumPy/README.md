# Chapter 8 - NumPy in Python

This chapter covers foundational concepts of **NumPy** (Numerical Python): array creation routines, dimensionality, shapes, 2D matrices, vectorization, and performance optimizations.

## Topics Covered
- Introduction to NumPy, importance, and advantages over standard Python lists
- Array creation routines: `np.array()`, `np.zeros()`, `np.ones()`, `np.arange()`, `np.linspace()`, `np.logspace()`
- 2D arrays (Matrices): Creating matrices from nested lists, built-in functions, reshaping
- Array attributes: `.shape`, `.ndim`, `.size`, `.dtype`
- Element-wise arithmetic, row/column operations, and matrix aggregations

## Files in this Chapter
- `numpy_basics.py`: Array creation, data types, vectorization, and speed benchmark vs Python lists.
- `array_creation.py`: Demonstrates `zeros()`, `ones()`, `arange()`, `linspace()`, and `logspace()`.
- `two_dimensional_arrays.py`: Creating 2D arrays, inspecting shapes, axis operations, and reshaping.
- `numpy_introduction.md`: 10-section study notes on array creation routines and core concepts.
- `numpy_2d_and_shapes.md`: 10-section guide on 2D arrays, shapes, dimensions, and indexing.

## How to Run
```bash
python numpy_basics.py
python array_creation.py
python two_dimensional_arrays.py
```
