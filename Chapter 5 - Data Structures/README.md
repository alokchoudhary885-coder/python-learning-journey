# Chapter 5 - Data Structures & Collections in Python

This chapter covers Python's built-in data structures (Lists, Tuples, Sets, and Dictionaries), their performance trade-offs, and practical manipulation patterns.

## Topics Covered
- Lists: Creation, Indexing, Slicing, and Mutability
- List Methods: `append`, `extend`, `insert`, `pop`, `remove`, `sort`, `reverse`
- List Comprehensions: Filtering, Transformation, and Conditional expressions
- Tuples: Immutability, packing, and unpacking (Up Next)
- Sets: Unordered unique collections and mathematical set operations (Up Next)
- Dictionaries: Key-value mapping and hash tables (Up Next)

## Files in this Chapter
- `list_operations.py`: Comprehensive runnable examples of indexing, slicing, methods, and comprehensions.
- `lists_in_python.md`: 10-section study notes on Python Lists with methods tables, memory rules, and practice questions.
- `tuple_operations.py`: Demonstration of tuple creation, immutability, packing/unpacking, and hashable keys.
- `tuples_in_python.md`: 10-section study notes on Python Tuples, single-element comma trap, and list vs tuple comparison.
- `dict_operations.py`: Dictionary operations, safe `.get()`, methods (`keys`, `values`, `items`, `update`), comprehensions, and nested JSON-like records.
- `dictionaries_in_python.md`: 10-section study notes on Python Dictionaries, hash tables, $O(1)$ search, and methods reference.

## How to Run
```bash
python list_operations.py
```
