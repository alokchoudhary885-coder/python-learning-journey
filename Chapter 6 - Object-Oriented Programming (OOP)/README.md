# Chapter 6 - Object-Oriented Programming (OOP) in Python

This chapter covers the foundations of Object-Oriented Programming (OOP): classes, objects, constructors, and the 4 fundamental pillars (Encapsulation, Abstraction, Inheritance, and Polymorphism).

## Topics Covered
- Introduction to OOP & Advantages over Procedural Programming
- Classes, Objects, and the `__init__` constructor
- The `self` reference, instance attributes vs class attributes
- Instance methods, class methods (`@classmethod`), and static methods (`@staticmethod`)
- Encapsulation: Public, Protected (`_`), and Private (`__`) attributes, getters & setters
- Abstraction: Abstract Base Classes (`ABC`) and `@abstractmethod`
- Inheritance: Single, Multiple, Multilevel, and the `super()` function
- Polymorphism: Method overriding, duck typing, and operator overloading

## Files in this Chapter
- `constructors.py`: Default, non-parameterized, parameterized constructors, default values, and `self` memory proof.
- `constructors.md`: 10-section study notes on constructors, types, lifecycle, and Q&A.
- `oop_methods.py`: Practical demonstration of Instance methods, Class methods (`@classmethod`), and Static methods (`@staticmethod`).
- `oop_methods.md`: 10-section comprehensive guide comparing the three method types with factory patterns.
- `variables_in_oop.py`: Instance vs class/static variables, namespaces (`__dict__`), and attribute shadowing.
- `variables_in_oop.md`: 10-section study notes on memory allocation, resolution order, and mutable variable traps.
- `class_and_objects.py`: Demonstrates class definitions, constructors, instance/class variables, and methods.
- `encapsulation.py`: Data hiding, private attributes, name mangling, and properties (`@property`).
- `abstraction.py`: Designing contracts with `ABC` and enforced abstract methods.
- `inheritance.py`: Single, multiple, multilevel inheritance, and `super()`.
- `polymorphism.py`: Method overriding and polymorphic function dispatch.
- `oop_advantages.md`: 10-section study notes on OOP concepts, advantages, and practice Q&A.
- `oop_principles.md`: 10-section comprehensive guide on the 4 pillars with diagrams and questions.
